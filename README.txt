00631L 戰術查詢器 PWA

用途：
- 可安裝到 iPhone / iPad 主畫面，以接近 App 的方式全螢幕開啟。
- 核心 70/30 與 Short Trade 分開管理。
- 資料使用瀏覽器 localStorage 儲存。

重要：
PWA 的「加入主畫面」與離線功能需要透過 HTTPS 網址開啟。
把整個資料夾上傳到 GitHub Pages、Cloudflare Pages、Netlify 或其他 HTTPS 靜態網站即可。

iPhone：
1. 用 Safari 開啟部署後網址
2. 點「分享」
3. 選「加入主畫面」
4. 點「加入」

檔案：
- index.html
- manifest.webmanifest
- sw.js
